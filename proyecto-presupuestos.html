Proyecto 01 // Automatización

Sistema de Automatización
de Presupuestos

Este proyecto nació de una necesidad real vivida en obra: la elaboración de presupuestos de construcción es un proceso tedioso, propenso a errores y que consume semanas enteras de trabajo manual. Un error en el metrado de una partida puede traducirse en pérdidas de miles de dólares.

La solución fue una aplicación web interactiva que permite al ingeniero o arquitecto ingresar los parámetros básicos del proyecto (tipo de estructura, área de construcción, especificaciones de materiales) y obtener de forma instantánea un presupuesto detallado, trazable y exportable a Excel o PDF.

El motor de cálculo fue desarrollado en Python con la librería pandas, conectado a una base de datos SQLite que almacena precios unitarios actualizables. El frontend interactivo fue construido en HTML/CSS con animaciones de datos en GSAP para visualizar en tiempo real cómo cambian los costos al modificar los parámetros.

Características Técnicas

  • Extracción y procesamiento automático de metrados desde plantillas estandarizadas.
  • Motor de cálculo estructural con fórmulas de la norma técnica de construcción local.
  • Base de datos de precios unitarios sincronizable con el mercado local de materiales.
  • Generación de reportes en PDF y Excel con un solo clic, listos para presentar al cliente.
  • Visualización interactiva de la distribución de costos mediante gráficos animados.
  • Sistema de control de versiones del presupuesto para rastrear cambios entre iteraciones.
  • Interfaz de usuario 100% responsiva y en modo oscuro, optimizada para uso en obra desde tablets.

Impacto y Resultados

La herramienta logró reducir el tiempo de elaboración de presupuestos de 5-7 días laborales a menos de 2 horas, eliminando prácticamente los errores de transcripción y aumentando la confianza de los clientes en la transparencia del proceso.

  • SQLite / SQLAlchemy
  • HTML5 / CSS3

  • ReportLab (PDF)
